# FishFrets: MPL-2.0 source files

[Fish Frets](https://fishfrets.bradleyfish.com) is a fretboard app by Bradley Fish and Phil Yastrow. It began as a fork of [Fretboarder](https://github.com/cheap-glitch/fretboarder) by cheap glitch, which is licensed under the Mozilla Public License 2.0.

This repository publishes the FishFrets files that are derived from Fretboarder, including FishFrets' changes to them, as the MPL requires. They are licensed under the MPL-2.0 (see [LICENSE](./LICENSE)).

The rest of FishFrets is proprietary and is not included here, so these files will not build on their own. They are updated with every FishFrets release.
